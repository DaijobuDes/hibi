# Introduction

The first time you open Hibi, a short introduction helps you set it up. It takes about a minute, and every step is optional.

## Steps

- **Welcome** explains what Hibi is.
- **Make it yours** sets the appearance to match your computer, or to light or dark, and chooses a colorscheme. Changes apply right away.
- **How you write** chooses the view new files open in and turns Markdown markers, spell check, the toolbar, and tabs on or off.
- **Your files** opens a folder as a workspace or opens a single file. Hibi keeps your writing in plain Markdown files on your computer, and it doesn't need an account.
- **Addons** turns on a few built-in addons. They all run on your computer.
- **Essentials** lists the shortcuts for the command palette, opening documents, the sidebar, and settings. If you changed a shortcut, the introduction shows yours.

Each choice changes the same setting you can find in [Settings](settings.md), so you can change it again later.

## Skip or reopen the introduction

Select **Skip** or press Escape to close the introduction at any step. It won't open automatically again.

If you open Hibi with a file the first time, or open a file from another app while the introduction is showing, the introduction waits until the next time you open Hibi on its own. A workspace Hibi reopens at startup doesn't make it wait.

To see it again, open the command palette and choose **Show introduction**, or select **Show introduction** in **Settings → About**.

## Keyboard and accessibility

Use Tab and Shift+Tab to move between controls, and Enter or Space to choose one. In the appearance and default view choices, use the arrow keys to change the selection. Focus stays inside the introduction until you close it, and screen readers announce each step's title and number. With your system's reduced-motion setting on, steps change without animation.
