# hibi

## Register

product

## Users

people writing markdown notes and documentation in local files and nested folders.

## Product Purpose

start typing immediately; edit visually, in markdown, or side by side. open a folder as a workspace and export documentation as a portable static site.

## Brand Personality

minimal, quiet, responsive. use vscode's file navigation and codex's sidebar-aware window chrome as references.

## Anti-references

avoid decorative panels, excess borders, large default gaps, flickering settings, and motion that repeatedly rewraps text.

## Design Principles

- keep writing central and secondary controls unobtrusive.
- share navigation across settings, workspaces, and exported documentation.
- preserve files and unsaved work through every view change.
- use subtle motion to explain state changes.

## Accessibility & Inclusion

retain keyboard navigation, visible focus, labeled controls, rebindable shortcuts, and reduced-motion alternatives.
